PART 1: ERROR EXPLANATION
--------------------------------------------------------------------------------
Q: "app crashed - waiting for file changes before starting.. kya mtlb hota hai?"

Ans:
Yeh message nodemon ka hota hai. Jab Node.js server chalte waqt kisi error ki
wajah se band (crash) ho jaata hai, tab nodemon yeh message deta hai.
Sabse aam wajah:
1. Port Conflict (EADDRINUSE :::4000):
   Port 4000 pe pehle se koi process chal raha tha aur naya server usi port pe
   start hone ki koshish kar raha tha.
2. Runtime Error / Crash:
   Code run hote waqt koi unhandled error aane par server ruk jaata hai.

"Waiting for file changes" ka matlab hai ki nodemon ruk gaya hai aur wait kar
raha hai ki aap kisi file me changes save karein ya terminal me 'rs' likhkar
Enter karein taaki wo server ko restart kar sake.
(Background process stop kar diya gaya hai, ab aap terminal me 'npm run server'
run kar sakte hain).
